## 🌌 **What is The Ouroboros Project?**
The Ouroboros Project is a **creative ecosystem** for building, exploring, and playing with **nested simulations**—whether through tabletop RPGs, software tools, or interactive experiences. At its core, it’s about:
- **Layered realities**: Stories, games, and systems that nest inside one another.
- **Collaboration**: Co-creating worlds, rules, and tools as a community.
- **Introspection**: Using these layers to explore identity, meaning, and connection.

> *"The ouroboros eats its own tail. We build the layers that build us."*

---

## 🏆 **Flagship: Hidden Gods**
Our first and primary project is **Hidden Gods**, a **Powered by the Apocalypse (PbtA) TTRPG** where players:
- Explore **nested simulation layers** (e.g., Debug, Dream, Base Reality).
- Encounter **anomalies** that hint at higher (or lower) layers.
- Use **Jungian archetypes** and **Internal Family Systems (IFS)** to navigate their characters’ inner worlds.
- Collaborate to **hack, build, or break** the simulation itself.

**Status**: 🟡 In development (see [`/hidden-gods`](hidden-gods/) for details).

## 🛠️ **Getting Started**
### For Players/Facilitators
- **Hidden Gods**: Check out the [`/hidden-gods`](hidden-gods/) directory for rules, moves, and lore.
- **Simulation Bible**: Contribute to the shared world in [`/docs`](docs/).

### For Developers
1. Clone the repo:
   ```bash
   git clone https://github.com/thejamesrf/ouroboros.git
   cd ouroboros
   ```
2. Install dependencies (if working on tools):
   ```bash
   pip install -e .
   ```
3. Explore the projects:
   - Hidden Gods: [`/hidden-gods`](hidden-gods/)
   - Tools: [`/src`](src/)
