# Ontos Phonology & Orthography
> *The sounds and symbols of precision.*

---

## 🔤 **Orthography: Symbol-Based Script**
Ontos uses a **symbol-based writing system** to eliminate ambiguity. Each symbol represents a **precise concept, operation, or entity**, and symbols can be combined to form complex ideas.

### **Why Symbols?**
- **Unambiguous**: No homophones or homographs.
- **Compact**: Complex ideas can be expressed concisely.
- **Universal**: Not tied to any natural language’s phonology.
- **Mathematical**: Aligns with Ontos’ logical foundation.

---

## 📜 **Symbol Categories**
Ontos symbols are divided into **categories** based on their function:

### **1. Logical Symbols**
| Symbol | Name          | Meaning                                                                 | Example                     |
|--------|---------------|-------------------------------------------------------------------------|-----------------------------|
| `⊤`    | Taut          | Absolute truth (always true).                                          | `⊤` = "True"                |
| `⊥`    | Contradiction | Absolute falsehood (always false). **Invalid in Ontos.**              | `⊥` = "False"               |
| `¬`    | Not           | Logical negation.                                                      | `¬A` = "Not A"              |
| `∧`    | And           | Logical conjunction.                                                   | `A ∧ B` = "A and B"         |
| `∨`    | Or            | Logical disjunction.                                                   | `A ∨ B` = "A or B"          |
| `→`    | Implies       | Logical implication.                                                   | `A → B` = "A implies B"      |
| `↔`    | Iff           | Logical equivalence (if and only if).                                  | `A ↔ B` = "A if and only if B" |
| `∀`    | ForAll        | Universal quantifier.                                                   | `∀x (P(x))` = "For all x, P(x)" |
| `∃`    | Exists        | Existential quantifier.                                                | `∃x (P(x))` = "There exists an x such that P(x)" |

### **6. Meta Symbols (Gödelian Awareness)**
| Symbol | Name          | Meaning                                                                 | Example                     |
|--------|---------------|-------------------------------------------------------------------------|-----------------------------|
| `⍵`    | Unknown       | Represents an unknown or unexpressible concept.                         | `⍵` = "Unknown"             |
| `⍶`    | Incomplete    | Denotes that a statement or system is incomplete.                      | `⍶(A)` = "A is incomplete"  |
| `⍷`    | Paradox       | **Invalid in Ontos.** Used to denote contradictions in other systems.   | `⍷` = "Paradox"             |
| `⍸`    | Self-Reference | Denotes self-referential statements (e.g., "This statement is true"). | `⍸(A)` = "A refers to itself" |

## 🗣️ **Phonology: Spoken Ontos**
While Ontos is primarily a **symbol-based language**, it can also be **spoken** using a standardized phonetic system. Each symbol is assigned a **unique phonetic representation** to avoid ambiguity.

### **Phonetic Mappings**
| Symbol | Phonetic Representation | Notes                                  |
|--------|--------------------------|----------------------------------------|
| `⊤`    | /tɔt/                   | Rhymes with "taut."                    |
| `⊥`    | /bɒt/                   | Rhymes with "bot."                     |
| `¬`    | /nɒt/                   | Rhymes with "not."                     |
| `∧`    | /ænd/                   | Like "and."                            |
| `∨`    | /ɔːr/                   | Like "or."                             |
| `→`    | /tuː/                   | Like "to."                             |
| `↔`    | /ɪf/                    | Like "if."                             |
| `∀`    | /fɔːl/                  | Like "for all."                        |
| `∃`    | /ɛks/                   | Like "exists."                         |
| `λ`    | /leɪ/                   | Like "layer."                          |
| `𝒢`    | /ɡɒd/                   | Like "god."                            |
| `⍢`    | /æn/                    | Like "anomaly" (shortened).             |
| `𝒫`    | /pliː/                  | Like "player."                         |

## 📏 **Symbol Combination Rules**
1. **No Ambiguity**: Symbols are combined in a **strict, hierarchical order** to avoid ambiguity.
   - Example: `A → (B ∧ C)` is valid; `A → B ∧ C` is **not** (parentheses are required).

2. **Parentheses**: Used to **group operations** and clarify order.
   - Example: `(A ∧ B) → C` vs. `A ∧ (B → C)`.

3. **Whitespace**: Optional for readability but **not required** for meaning.
   - Example: `A→B` is equivalent to `A → B`.

4. **Prefix/Infix/Postfix**: Symbols have **fixed positions** relative to their operands.
   - `¬A` (prefix: negation).
   - `A ∧ B` (infix: conjunction).
   - `A!` (postfix: factorial, if adopted).

## 📝 **Example Texts**
### **Example 1: Basic Logic**
**Ontos**:
```
(∀x (x ∈ λ_Debug)) → (∃y (y = ⍢_EchoingDoor))
```
**Phonetic**:
```
/fɔːl ɛks ɪn leɪ_Debug tuː ɛksɪsts waɪ y = æn_ɛkoʊɪŋ dɔːr/
```
**English**:
```
For all x in the Debug Layer, there exists a y such that y is the Echoing Door.
```

---

### **Example 2: Hidden Gods Scenario**
**Ontos**:
```
𝒫_Alice → (λ_Debug ∧ ⍢_EchoingDoor) → (𝒢_Architect → ⍢_NewAnomaly)
```
**Phonetic**:
```
/pliː_ælɪs tuː leɪ_Debug ænd æn_ɛkoʊɪŋ dɔːr tuː ɡɒd_ɑːkɪtɛkt tuː æn_njuː_ænɒməli/
```
**English**:
```
Player Alice, in the Debug Layer with the Echoing Door, implies that the Architect creates a new anomaly.
```

---

### **Example 3: Gödelian Statement**
**Ontos**:
```
⍶(Ontos) ∧ (Ontos → ⍵)
```
**Phonetic**:
```
/ɪnˈkɒmpliːt Ontos ænd Ontos tuː ʌnnoʊn/
```
**English**:
```
Ontos is incomplete, and Ontos implies the unknown.
```
