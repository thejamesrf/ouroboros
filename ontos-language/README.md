# Ontos Language
> <span style="background-color: #2196F3; color: white; padding: 2px 6px; border-radius: 4px;">🔵 Logic</span>
> <span style="background-color: #FF9800; color: white; padding: 2px 6px; border-radius: 4px;">🟠 Precision</span>
> *A constructed language (conlang) for left-brain thought: specificity, non-contradiction, and while it pursues completeness in the face of Gödelian incompleteness, it prioritizes consistency over completeness while absolutely avoiding inconsistent or paradoxical reasoning.*

---

## 🧠 **Philosophy**
Ontos is a **formal, logical language** designed to:
- **Represent left-brain thought**: Structured, analytical, and precise.
- **Avoid contradiction**: A language where paradoxes are impossible by design.
- **Embrace incompleteness**: Inspired by **Gödel’s Incompleteness Theorems**, Ontos acknowledges that no system can fully describe itself—but it strives to **minimize gaps**.
- **Drive toward non-incompleteness**: While incompleteness is inevitable, Ontos seeks to **push the boundaries** of what can be expressed without contradiction.

> *"Ontos is the language of the Architect: a tool for building layers of reality without cracks."*

---

## 🌌 **Connection to Hidden Gods**
Ontos is **part of the Hidden Gods saga** as:
- The **language of the Hidden Gods** (or their agents) who administer higher simulation layers.
- A **tool for players** to describe anomalies, layers, or mechanics with **mathematical precision**.
- A **metaphor for the simulation itself**: Just as Ontos seeks to avoid contradiction, the simulation layers of Hidden Gods are **self-consistent** (until they’re not).

> *"The Debug Layer is written in Ontos. To hack it, you must think in Ontos."*

## 📚 **Core Principles**
| Principle               | Description                                                                                     | Example in Ontos                          |
|-------------------------|-------------------------------------------------------------------------------------------------|-------------------------------------------|
| **Non-Contradiction**   | No statement in Ontos can be both true and false in the same context.                          | `A = A` is valid; `A = ¬A` is invalid.      |
| **Specificity**         | Every term must have a **single, unambiguous meaning** in a given context.                     | `"Door"` is distinct from `"GlitchingDoor"`. |
| **Completeness**        | The language aims to **cover all possible concepts** in its domain (though Gödel tells us this is impossible). | Ontos includes symbols for time, space, and simulation layers. |
| **Gödelian Awareness** | Ontos **acknowledges its own limits**—it cannot fully describe itself, but it tries to get as close as possible. | Meta-symbols for "unknown" or "unexpressible." |
| **Left-Brain Focus**    | Designed for **logical, sequential thought**—the opposite of the Dream Layer’s fluidity.       | Syntax is rigid and hierarchical.          |

## 🔤 **Language Structure**
### **1. Phonology & Orthography**
Ontos uses a **symbol-based script** (like mathematical notation) to avoid ambiguity. Each symbol represents a **precise concept** or operation.

**Example Symbols**:
| Symbol | Name          | Meaning                                                                 |
|--------|---------------|-------------------------------------------------------------------------|
| `⊤`    | *Taut*        | Absolute truth (e.g., `A = A`).                                         |
| `⊥`    | *Contradiction* | Absolute falsehood (e.g., `A = ¬A`). **Invalid in Ontos.**             |
| `→`    | *Implies*     | Logical implication (e.g., `A → B`).                                   |
| `≡`    | *Equiv*       | Logical equivalence (e.g., `A ≡ B`).                                   |
| `∃`    | *Exists*      | Existential quantifier (e.g., `∃x (P(x))`).                            |
| `∀`    | *ForAll*      | Universal quantifier (e.g., `∀x (P(x))`).                              |
| `λ`    | *Layer*       | Denotes a simulation layer (e.g., `λ_Debug`).                          |
| `𝒢`    | *God*         | Denotes a Hidden God (e.g., `𝒢_Architect`).                            |
| `⍢`    | *Anomaly*     | Denotes an anomaly (e.g., `⍢_EchoingDoor`).                            |

### **2. Grammar**
Ontos is **fully regular** with no exceptions. Sentences follow a **strict hierarchical structure**:
```
[Subject] [Predicate] [Object]
```
**Example**:
```
𝒢_Architect → λ_Debug (⍢_EchoingDoor)
```
*Translation*: "The Architect implies the Echoing Door in the Debug Layer."

### **3. Semantics**
- **No synonyms**: Each concept has **one and only one symbol/word**.
- **No polysemy**: Each symbol/word has **one and only one meaning** in a given context.
- **Contextual layers**: Meanings can shift between simulation layers (e.g., `λ_Debug` vs. `λ_Dream`).

## 📖 **Examples**
### **Basic Statements**
| Ontos                          | English Translation                          | Notes                                  |
|--------------------------------|---------------------------------------------|----------------------------------------|
| `∃x (x ∈ λ_Debug)`             | "There exists an x in the Debug Layer."     | `∈` = "is in."                          |
| `𝒢_Architect → (λ_Debug ≡ λ_Code)` | "The Architect implies the Debug Layer is the Code Layer." | `≡` = "is equivalent to." |
| `⍢_EchoingDoor → (∀t (t - 3s))` | "The Echoing Door implies all time is delayed by 3 seconds." | `t` = time; `-` = subtraction. |

### **Hidden Gods Use Case**
**Scenario**: A player rolls **Hack the Code** in the Debug Layer.
**Ontos Description**:
```
Player → (λ_Debug ∧ ⍢_EchoingDoor) → (𝒢_Architect → ⍢_NewAnomaly)
```
*Translation*: "The Player, in the Debug Layer with the Echoing Door, implies that the Architect creates a new anomaly."
