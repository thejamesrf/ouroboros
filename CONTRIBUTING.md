# Contributing to The Ouroboros Project
> *Thank you for helping build the layers of reality!*

---

## 📌 **How to Contribute**
We welcome contributions from everyone! Here’s how you can help:

### **1. Reporting Issues**
- Use the [GitHub Issues](https://github.com/thejamesrf/ouroboros/issues) template.
- Include:
  - A **clear description** of the issue.
  - **Steps to reproduce** (if applicable).
  - **Screenshots** (if applicable).

### **2. Suggesting Features**
- Open an issue with the **enhancement** label.
- Describe:
  - **What** you want to add.
  - **Why** it’s valuable.
  - **How** it fits into the project.

### **3. Submitting Changes**
1. **Fork the repo** and create a branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. **Make your changes** and test them.
3. **Commit** with a clear message:
   ```bash
   git commit -m "feat(hidden-gods): add simulation_bible.md"
   ```
4. **Push** and open a PR.

## 📜 **Style Guidelines**

### **Markdown**
- Use **colored tags** for categories (e.g., `🟢 World-Building`).
- Use **tables** for structured data (e.g., anomalies, layers).
- Keep **lines under 80 chars** for readability.

### **Python**
- Follow **PEP 8** and **type hints**.
- Use **dataclasses** for data models.
- Include **docstrings** for all functions.

### **JavaScript/React Native**
- Use **functional components** and **hooks**.
- Follow **ESLint** rules.
- Include **PropTypes** or **TypeScript** for type safety.

### **Git**
- Use **conventional commits** (`feat:`, `fix:`, `docs:`, `chore:`).
- **Squash** small commits before merging.

## 🚀 **Getting Started**
1. Clone the repo:
   ```bash
   git clone https://github.com/thejamesrf/ouroboros.git
   cd ouroboros
   ```
2. Install dependencies (if working on tools):
   ```bash
   pip install -r hidden-gods-app/requirements.txt
   ```
3. Explore the projects:
   - Hidden Gods: [`/hidden-gods`](hidden-gods/)
   - Ontos Language: [`/ontos-language`](ontos-language/)
   - Mobile App: [`/hidden-gods-mobile`](hidden-gods-mobile/)
