|-----------|------------|----------------|

| The Orphan | Belongs, fits in | Cynicism, conformity |
| The Hero | Overcomes adversity | Arrogance, violence |
| The Caregiver | Nurtures, protects | Martyrdom, control |
| The Explorer | Discovers, escapes | Restlessness, aimlessness |
| The Rebel | Challenges, disrupts | Destructiveness, alienation |
| The Lover | Connects, experiences | Addiction, obsession |
| The Creator | Imagines, innovates | Perfectionism, detachment |
| The Jester | Enjoys, plays | Irresponsibility, cruelty |
| The Sage | Understands, seeks truth | Dogmatism, inaction |
| The Magician | Transforms, manifests | Manipulation, deception |
| The Ruler | Controls, orders | Tyranny, rigidity |
